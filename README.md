# Promethium Asteroid Stacking
Factorio 2.1 Mod by: [jatmn](https://mods.factorio.com/user/jatmn)

Requires Factorio 2.1 with Space Age 2.1.21 or newer. For Factorio 2.0, use mod version 0.0.1.

I made this mod because at the time, I didn't see a mod that existed yet that actually did just this.

This is just the initial release for my own playthrough.. but if more features are requested, I might add them
